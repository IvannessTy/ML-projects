# Анализ и прогнозирование цен на недвижимость Москвы

Проект по интеллектуальному анализу данных, посвящённый прогнозированию стоимости недвижимости в Москве.

В проекте решаются две задачи регрессии:

1. **Прогнозирование цены продажи квартиры**
2. **Прогнозирование арендной ставки**

Для обеих задач проводится полный цикл анализа данных: от EDA и предобработки до построения, настройки и сравнения нескольких моделей машинного обучения.

## Основные задачи проекта

### 1. Прогнозирование цены продажи

Используется датасет сделок с квартирами Москвы за I квартал 2026 года.

В ходе работы:

- проведён разведочный анализ данных;
- исследованы пропуски, распределения и выбросы;
- очищены некорректные значения цены и площади;
- обработаны признаки этажа, года постройки и материала стен;
- рассчитан возраст здания;
- кадастровый квартал использован как признак расположения;
- целевая переменная логарифмирована;
- категориальные признаки закодированы;
- числовые признаки масштабированы;
- проведено сравнение нескольких моделей регрессии.

Для кадастрового квартала используется **Target Encoding**, поскольку количество уникальных значений слишком велико для обычного one-hot encoding.

### 2. Прогнозирование стоимости аренды

Вторая часть проекта посвящена прогнозированию арендной ставки квартиры в Москве.

Исходный датасет был дополнительно обогащён географическими признаками на основе данных **OpenStreetMap**:

- расстояние до ближайшего метро;
- расстояние до ближайшего парка;
- количество кафе и ресторанов в радиусе 500 метров;
- количество магазинов в радиусе 500 метров.

Для получения этих признаков использовались библиотеки `geopandas` и `osmnx`.

Дополнительно были созданы признаки, описывающие:

- возраст здания;
- относительное положение квартиры по этажам;
- площадь комнаты;
- отношение площади кухни к общей площади;
- удалённость от центра и другие характеристики объекта.

## Используемые модели

Для обеих задач сравнивались модели различной природы:

- Ridge Regression
- K-Nearest Neighbors
- Decision Tree
- Random Forest
- Gradient Boosting
- Support Vector Regression
- MLPRegressor

Для части моделей основные гиперпараметры подбирались с использованием кросс-валидации.

## Метрики качества

Так как обе задачи являются задачами регрессии, используются:

- **R²** — доля объяснённой дисперсии;
- **RMSE** — среднеквадратичная ошибка;
- **MAE** — средняя абсолютная ошибка.

Целевая переменная предварительно логарифмируется, поэтому RMSE и MAE рассчитываются в логарифмической шкале.

## Результаты

### Цена продажи

| Модель | R² | RMSE | MAE |
|---|---:|---:|---:|
| Gradient Boosting | **0.661** | **0.479** | **0.315** |
| Random Forest | 0.656 | 0.483 | 0.317 |
| SVR | 0.627 | 0.502 | 0.318 |
| MLP | 0.627 | 0.502 | 0.321 |
| KNN | 0.618 | 0.508 | 0.337 |
| Decision Tree | 0.609 | 0.514 | 0.341 |
| Ridge | 0.451 | 0.609 | 0.427 |

Лучший результат показал **Gradient Boosting** с `R² = 0.661`.

Наиболее значимые признаки:

- площадь квартиры;
- кадастровый квартал.

Таким образом, основными факторами стоимости продажи оказываются **размер объекта и его расположение**.

### Арендная ставка

| Модель | R² | RMSE | MAE |
|---|---:|---:|---:|
| Random Forest | **0.942** | **0.197** | **0.142** |
| Gradient Boosting | 0.927 | 0.221 | 0.166 |
| SVR | 0.915 | 0.239 | 0.179 |
| MLP | 0.906 | 0.251 | 0.192 |
| KNN | 0.903 | 0.255 | 0.192 |
| Decision Tree | 0.902 | 0.257 | 0.191 |
| Ridge | 0.899 | 0.260 | 0.199 |

Лучший результат показал **Random Forest** с `R² = 0.942`.

Среди наиболее важных признаков оказались:

- площадь квартиры;
- удалённость от центра;
- этажность здания;
- количество кафе поблизости.

Результаты показывают, что для стоимости аренды характеристики расположения объекта оказываются практически так же важны, как его площадь.

## Предобработка данных

В проекте применяются:

- удаление явных выбросов;
- обработка пропущенных значений;
- медианная импутация числовых признаков;
- `StandardScaler`;
- One-Hot Encoding;
- Target Encoding;
- генерация дополнительных признаков;
- логарифмирование целевой переменной.

Разделение данных производится на обучающую и тестовую выборки в соотношении **80/20**.

## Основные выводы

В обеих задачах лучшие результаты показали **ансамблевые модели на основе деревьев** — Random Forest и Gradient Boosting.

Линейная модель уступает им, поскольку зависимость стоимости недвижимости от характеристик объекта является существенно нелинейной.

В обеих задачах двумя ключевыми группами факторов являются:

1. **характеристики самой квартиры**, прежде всего площадь;
2. **расположение объекта**.

Дополнительные географические признаки, полученные из OpenStreetMap, позволяют подробнее описать окружение объекта и использовать эту информацию при прогнозировании стоимости аренды.

## Возможное применение

Полученные модели могут использоваться как основа сервиса автоматической оценки недвижимости.

Например, модель можно встроить в форму создания объявления: пользователь указывает параметры квартиры и получает ориентировочную рыночную стоимость продажи или аренды.

Такой инструмент может помочь:

- быстрее определить адекватную цену;
- снизить количество переоценённых и недооценённых объявлений;
- упростить процесс размещения недвижимости на платформе.
