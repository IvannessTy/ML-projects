# Классификация видов пингвинов с помощью KNN

Проект по классификации видов пингвинов на основе физических характеристик.

В работе используется метод k ближайших соседей. Помимо модели из `scikit-learn`, реализована собственная версия KNN на NumPy.

## Основные задачи проекта

- подготовка данных Palmer Penguins;
- обработка пропусков;
- кодирование категориальных признаков;
- train/test split со стратификацией;
- масштабирование признаков;
- обучение KNN с разными значениями `k`;
- визуализация решающих границ;
- реализация KNN с нуля;
- сравнение поведения модели при разных значениях `k`.

## Модель

Используется `KNeighborsClassifier` с евклидовой метрикой.

Для визуализации решающей поверхности используются два признака:

- длина ласта;
- масса тела.

Отдельно реализован класс `KNN`, который:

1. сохраняет обучающую выборку;
2. считает расстояния от нового объекта до объектов train;
3. выбирает `k` ближайших соседей;
4. определяет класс голосованием.

## Результаты

При `k=1` граница получается сложной и чувствительной к отдельным объектам. При увеличении `k` граница становится более гладкой.

Для собственной реализации дополнительный поиск дал лучший результат:

```text
k = 40
accuracy = 0.7857142857142857
```

## Предобработка данных

В проекте применяются:

- удаление строк с пропусками;
- One-Hot Encoding;
- отдельное кодирование целевой переменной;
- `StandardScaler`;
- стратифицированный train/test split.

Масштабирование обучается только на train и затем применяется к test.

## Основные выводы

KNN чувствителен к выбору числа соседей. Слишком маленькое `k` увеличивает риск переобучения, а слишком большое приводит к сильному усреднению.

Визуализация решающих границ показывает эту зависимость. Собственная реализация KNN позволяет отдельно разобрать механику алгоритма.
