# Классификация тональности твитов

Проект по бинарной классификации эмоциональной окраски твитов о коронавирусе.

Целевая переменная принимает два значения:

- `1` - положительный твит;
- `0` - отрицательный твит.

В проекте сравниваются разные способы представления текста и исследуется влияние очистки словаря на качество Logistic Regression.

## Основные задачи проекта

- подготовка текстовых данных;
- анализ баланса классов;
- работа с пропусками;
- анализ частотности токенов;
- токенизация Twitter-текстов;
- удаление stop words, пунктуации, ссылок и шумных символов;
- собственный tokenizer;
- CountVectorizer;
- TF-IDF;
- Logistic Regression;
- stemming;
- фильтрация редких токенов через `min_df`;
- анализ влияния масштабирования;
- дополнительный анализ даты публикации твита.

## Данные

Используются твиты о коронавирусе.

Основные признаки:

- `Location`;
- `TweetAt`;
- `OriginalTweet`;
- `Sentiment`.

После объединения исходных классов задача становится бинарной.

Распределение классов:

```text
positive ≈ 53.96%
negative ≈ 46.04%
```

Сильного дисбаланса классов нет.

## Токенизация

Для обработки текста используется `TweetTokenizer`.

Дополнительно из текста удаляются:

- английские stop words;
- пунктуация;
- ссылки `https://t.co`;
- отдельные шумные символы.

Для этой логики реализована собственная функция `custom_tokenizer`.

## Векторизация

Сравниваются два подхода:

- CountVectorizer;
- TF-IDF.

Размер словаря CountVectorizer после базовой очистки:

```text
45 290 токенов
```

## Модель

Для классификации используется Logistic Regression.

Результаты без stemming:

```text
CountVectorizer:
train accuracy = 0.9847
test accuracy  = 0.8671

TF-IDF:
train accuracy = 0.9224
test accuracy  = 0.8528
```

CountVectorizer показал лучшее качество на test.

## Stemming

Для stemming используется `SnowballStemmer`.

После stemming размер словаря уменьшился:

```text
45 290 -> 36 634 токена
```

Результаты:

```text
CountVectorizer + stemming:
train accuracy = 0.9720
test accuracy  = 0.8675

TF-IDF + stemming:
train accuracy = 0.9166
test accuracy  = 0.8560
```

Stemming заметно уменьшил число признаков, но почти не изменил качество CountVectorizer.

## Фильтрация редких слов

После установки:

```python
min_df=11
```

размер словаря сократился до:

```text
3 687 признаков
```

Результат модели:

```text
train accuracy = 0.9290
test accuracy  = 0.8680
```

Это лучший test accuracy среди проверенных в notebook вариантов.

## Масштабирование

Дополнительно проверено масштабирование sparse-признаков через:

```python
StandardScaler(with_mean=False)
```

После него test accuracy снизился до:

```text
0.8447
```

В этом эксперименте масштабирование не улучшило модель.

## Основные выводы

CountVectorizer в этой задаче показал качество выше TF-IDF.

Stemming позволил сильно сократить словарь без заметной потери test accuracy.

Дополнительное удаление редких токенов уменьшило число признаков почти в 10 раз и немного улучшило test accuracy.

Не все дополнительные признаки оказываются полезными: масштабирование текстовых признаков и дата публикации улучшения не дали.
