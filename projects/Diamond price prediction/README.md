# Прогнозирование цены бриллиантов

Проект по прогнозированию стоимости бриллиантов на основе физических и категориальных характеристик.

Основной акцент сделан на линейных моделях, мультиколлинеарности и влиянии L1/L2 регуляризации.

## Основные задачи проекта

- анализ структуры данных;
- удаление технических признаков;
- анализ корреляций;
- One-Hot Encoding категориальных признаков;
- train/test split;
- стандартизация числовых признаков;
- обучение Linear Regression;
- анализ коэффициентов;
- сравнение Ridge и Lasso;
- анализ влияния регуляризации на веса модели.

## Используемые модели

- Linear Regression
- Ridge Regression
- Lasso Regression

## Анализ признаков

Наиболее сильная линейная связь с ценой наблюдается у:

- `carat`;
- `x`;
- `y`;
- `z`.

Эти признаки описывают размер бриллианта и ожидаемо оказываются тесно связаны с его стоимостью.

## Регуляризация

В данных есть сильно коррелирующие признаки, поэтому дополнительно сравниваются Ridge и Lasso.

Ridge уменьшает абсолютные значения коэффициентов без их полного зануления.

Lasso может занулять отдельные коэффициенты и тем самым выполнять отбор признаков.

## Предобработка данных

В проекте применяются:

- удаление технического столбца;
- One-Hot Encoding;
- `StandardScaler`;
- train/test split.

Scaler обучается только на train и затем применяется к test.

## Метрика качества

Для сравнения моделей используется MSE:

```text
Mean Squared Error
```

## Основные выводы

Линейная регрессия дает понятный baseline и позволяет анализировать влияние признаков через коэффициенты.

При наличии сильно коррелирующих признаков регуляризация делает веса модели более устойчивыми. Lasso дополнительно подходит для отбора признаков, а Ridge позволяет уменьшить веса без жесткого зануления.
