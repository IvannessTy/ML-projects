# Линейная регрессия и градиентный спуск с нуля

Проект по реализации линейной регрессии и нескольких вариантов градиентной оптимизации на NumPy.

Основная цель проекта: разобрать внутреннюю механику обучения линейной модели, а не использовать готовый `.fit()` из `scikit-learn`.

## Основные задачи проекта

- реализация Mean Squared Error;
- вычисление градиента MSE;
- обычный Gradient Descent;
- Stochastic / Mini-batch Gradient Descent;
- затухающий learning rate;
- анализ влияния шага обучения;
- анализ влияния размера batch;
- собственный класс LinearRegression;
- L2 регуляризация;
- Huber Loss;
- применение модели к реальному датасету автомобилей.

## Gradient Descent

В первой части проекта исследуется поведение градиентного спуска при разных параметрах.

Рассматриваются:

- обычный градиентный спуск;
- стохастический вариант;
- mini-batch обучение;
- разные значения learning rate;
- разные размеры batch;
- затухание шага в процессе обучения.

## Собственная Linear Regression

Реализован класс с интерфейсом:

```python
model.fit(X_train, y_train)
model.predict(X_test)
```

При этом обучение весов внутри выполняется собственной реализацией градиентного спуска.

## Прикладная задача

Модель применяется к задаче прогнозирования стоимости автомобиля.

Перед обучением выполняются:

- train/test split;
- обработка пропусков;
- стандартизация числовых признаков;
- One-Hot Encoding категориальных признаков;
- выравнивание столбцов train и test.

## Результаты

Базовая модель с MSE:

```text
train MSE ≈ 29.2 млн
test MSE ≈ 68.6 млн
```

После добавления L2 регуляризации проверено несколько коэффициентов. Лучший из рассмотренных вариантов:

```text
L2 coefficient = 0.0005
test MSE ≈ 68.58 млн
```

Также реализован Huber Loss. На этом датасете он показал результат хуже обычного MSE, поэтому базовый MSE остался более удачным вариантом.

## Основные выводы

Скорость и стабильность градиентного спуска сильно зависят от learning rate и размера batch.

Стохастический градиент дает более шумную траекторию, но позволяет обновлять веса без полного прохода по выборке на каждом шаге.

L2 регуляризация немного улучшила test MSE в проведенном эксперименте. Huber Loss в этой задаче улучшения не дал.
